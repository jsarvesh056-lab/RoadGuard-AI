🌍 About the Project

RoadGuard AI is an intelligent road safety system designed to identify potential road hazards, detect accident situations and improve emergency response. By combining Artificial Intelligence, Computer Vision and GPS technology, the system aims to support faster incident reporting, accurate location sharing and effective emergency coordination.

🎯 Problem Statement

Road accidents remain a serious challenge in India. Delayed emergency response, limited real-time accident detection and inaccurate incident location reporting can increase the risk to victims.

RoadGuard AI aims to address these challenges through an intelligent and connected road safety solution.

💡 Key Features

- AI-powered road hazard detection.
- Accident situation detection.
- GPS-based accident location sharing.
- Real-time incident alerts.
- Emergency response coordination.
- Centralised incident monitoring dashboard.

Features are being developed and will be implemented progressively.

🛠️ Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Local Server: XAMPP (Apache)
- AI & Computer Vision: Python, OpenCV
- Location Services: GPS and Geolocation API
- Version Control: Git and GitHub

⚙️ Installation and Setup

1. Install XAMPP.
2. Clone or download this repository.
3. Place the project inside the XAMPP htdocs directory, or configure Apache to access the repository folder.
4. Start Apache and MySQL from XAMPP.
5. Open your browser.
6. Visit:

"http://localhost/RoadGuard-AI/"
